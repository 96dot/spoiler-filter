# Security policy

NoVice runs on every page you visit, so a security problem in it can affect any site. Report one privately.

## Report a problem

[Open a private report](https://github.com/kpulka247/novice/security/advisories/new) on GitHub. Only the maintainer can read it. Include:

- What an attacker can do, and on which pages.
- The steps to reproduce it.
- The NoVice version and the browser.

Do not open a public issue or pull request for a security problem until a fix is released.

## What happens next

You get a reply within 7 days. If the report is valid, the fix ships in a patch release, and the advisory credits you unless you ask not to be named.

## Supported versions

Only the latest release gets security fixes. The browser stores update the extension automatically.
